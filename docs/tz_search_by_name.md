# ТЗ: Поиск персонажей по имени

## Суть задачи

Сейчас приложение загружает первые 20 персонажей и просто показывает их списком. Пользователь не может найти конкретного персонажа — он вынужден листать всё подряд.

Нужно добавить строку поиска. Пользователь вводит имя (например "Rick") — и список обновляется, показывая только подходящих персонажей. Данные берутся с API, а не фильтруются из уже загруженных 20 штук.

---

## Что должно появиться в интерфейсе

На экране "Characters" над списком добавляется поле ввода текста (`TextField`). Пока оно пустое — показывается обычный список. Как только пользователь начинает вводить текст — список обновляется автоматически (не нужно нажимать кнопку).

---

## Как это работает изнутри

API поддерживает поиск через параметр в адресе:

```
/character?name=rick   → вернёт всех персонажей с "rick" в имени
/character             → вернёт первые 20 персонажей (как сейчас)
```

То есть при каждом изменении текста в поле — отправляется новый запрос на API с введённым именем.

---

## Что нужно сделать по шагам

**1. API** — в `lib/data/api/api_client.dart` изменить метод `getCharacters()` так, чтобы он принимал необязательный параметр `name` и передавал его в запрос.

**2. Event** — в `lib/bloc/characters/characters_event.dart` добавить новое событие `SearchCharacters` с полем `query` (строка поиска).

**3. Bloc** — в `lib/bloc/characters/characters_bloc.dart` добавить обработчик для `SearchCharacters`: он делает то же самое что `FetchCharacters`, но передаёт имя в API.

**4. UI** — в `lib/screens/characters_screen.dart` добавить `TextField` над списком. При каждом изменении текста — отправлять событие `SearchCharacters` в Bloc.

---

## Крайние случаи (edge cases)

| Ситуация | Что показать |
|---|---|
| Поле пустое | обычный список первых 20 персонажей |
| Персонажи найдены | показать их списком |
| Никто не найден | текст "Ничего не найдено" |
| Ошибка сети | текст с ошибкой + кнопка "Повторить" |
| Идёт загрузка | крутящийся спиннер |

---

## Что НЕ нужно делать

- Не нужно хранить историю поиска
- Не нужно искать по виду, статусу или полу — только по имени
- Не нужно добавлять кнопку "Найти" — поиск работает автоматически при вводе

---

## Как понять, что задача выполнена

1. Открыть экран "Characters"
2. Ввести "Rick" в поле поиска
3. Список обновился и показывает только персонажей с "Rick" в имени
4. Очистить поле — список вернулся к обычному виду
5. Ввести "xyzxyzxyz" — появилось сообщение "Ничего не найдено"
